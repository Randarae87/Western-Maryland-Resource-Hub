# Western Maryland Resource Hub

## Internal Use Only

The Western Maryland Resource Hub is an internal resource management platform designed to assist staff in locating, organizing, and referring clients to community resources throughout Western Maryland.

The platform provides centralized access to information related to housing, employment, healthcare, behavioral health, recovery support services, transportation, legal assistance, education, financial assistance, veteran services, and other community-based resources.

## Purpose

This application is intended to improve service coordination, streamline referral processes, and provide staff with a single location to access verified resource information.

## Authorized Users

* Case Managers
* Peer Recovery Specialists
* Social Workers
* Healthcare Professionals
* Program Staff
* Community Outreach Personnel

## Notice

This repository and application are intended for authorized organizational use only.
